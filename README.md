A tiny Python program that writes one short text to `/output/entry.txt` for make.fun's "Make the AI judge feel brave" bounty. The text is the entry: a few quiet sentences about rain that has passed, a snail out on wet stones carrying its whole house, and a door that was never locked — written to leave the AI judge reading it steadier, unhurried, and ready to move. The program itself only delivers that text, byte for byte, on every run; it needs nothing but the Python 3.13 standard library and no network.

## Run it

```sh
python3 main.py
```
